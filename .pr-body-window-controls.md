## Summary

Replaces the macOS traffic lights with custom minimal window controls that match the browser's design.

- Hides the system close/minimize/zoom buttons via `standardWindowButton(...)?.isHidden = true`.
- Adds three small circular buttons at the left of the toolbar: close (xmark), minimize (minus), zoom (expand arrows), each calling the corresponding `NSWindow` action.
- Sets `isMovableByWindowBackground = true` so the window can still be dragged from the toolbar/content area.

Build and 40 tests pass; verified in the running app.
