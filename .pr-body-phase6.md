## Summary

Phase 6 of the OPENMXC spec: privacy and security foundations.

- **Private browsing windows** — ⌘⇧N opens a separate window group whose tabs use a non-persistent `WKWebsiteDataStore`: no cookies or storage persist, history is never recorded, and private windows are excluded from session save/restore. The sidebar shows a purple "Private" indicator.
- **Website permissions** — camera, microphone, camera+microphone and geolocation requests are routed through `WKUIDelegate` to a new `PermissionManager` that remembers per-origin allow/deny decisions ("Remember for this website") in the settings table, with an `NSAlert` prompt otherwise. Decisions never bypass WebKit's own permission flow.
- **Tracking protection** — a small built-in content-blocking rule list compiled through `WKContentRuleListStore` and applied to every regular (non-private) web view configuration; toggle persisted in settings, compiled asynchronously at launch so startup is not blocked.
- **Clear website data** — History library gains a "Clear Cookies and Website Data…" action that wipes WebKit cookies/caches/storage via `WebsiteDataManager` after confirmation; SQLite data (bookmarks, history) is untouched.
- **URL scheme validation** — `decidePolicyFor navigationResponse` now cancels non-http(s) responses (downloads handled separately); existing action-level scheme handling (hand non-web schemes to the OS) retained. No certificate-error bypass added.
- **JavaScript messaging audit** — the app performs no `evaluateJavaScript` except the single mute-state toggle injected into the page's own web view; no `WKScriptMessageHandler` or user-script content world is registered anywhere, so there is no JavaScript→native messaging surface to audit further.

Tests: 6 new `PrivacyTests` (permission persistence/reset, private-tab data store wiring, tracking-protection default/toggle) — 40 tests total passing.

Verified end-to-end: opened a private window with ⌘⇧N, navigated to a unique URL, confirmed the page loaded with the "Private" indicator, confirmed the URL never appears in `history_visits`, quit and relaunched — only normal windows were restored.
