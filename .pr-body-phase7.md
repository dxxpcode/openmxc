## Summary

Phase 7 of the OPENMXC spec: native macOS refinement.

- **Native menus** — `BrowserCommands` adds File/View/Window menu items (New Tab ⌘T, New Private Window ⇧⌘N, Close Tab ⌘W, Close Window ⇧⌘W, Focus Address Bar ⌘L, Toggle Sidebar ⌃⌘S, Add to Favorites ⌘D, Select Tab ⌘1–9, next/previous tab ⇧⌘[/]). Commands post notifications; each window handles them only when it is the key window (via a `WindowAccessor`), so multi-window setups behave correctly. This replaces the hidden keyboard-shortcut buttons hack.
- **Settings window** (⌘,) — General (default search engine picker persisted to `search_engines`, onboarding toggle), Appearance (System/Light/Dark theme applied app-wide via `preferredColorScheme`), Privacy (tracker-blocking toggle, per-website permission list with reset, clear cookies and website data), Downloads (location info), About.
- **First-launch onboarding** — optional 3-screen flow (welcome, search engine + appearance, ready) with Skip; completion stored in settings and it never appears for private windows.
- **Share sheet** — toolbar share button using SwiftUI `ShareLink` for the current page URL.
- **Accessibility** — tab rows are now single accessible elements with combined labels (title, host, muted/pinned/selected state) and a double-tap action; toolbar buttons have explicit accessibility labels; decorative icons hidden from VoiceOver.
- **Finder integration** — already present from Phase 5 (Reveal in Finder for downloads); full-screen behavior comes from `isElementFullscreenEnabled` in the web view configuration.

Verified end-to-end: onboarding appears on first launch and Skip persists; ⌘T creates tabs, ⌘1 selects, ⌘L focuses only the key window's address bar, ⌘, opens Settings with all five tabs. 40 tests passing.
